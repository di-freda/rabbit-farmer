# rabbit farmer 🐰🧑‍🌾

What do you get when a rabbit believes that the carrots on your farm belong to it? A rabbit farmer.
Rabbit farmer is a simple and fun top-down style game with a simple gameplay. The rabbit wants to harvest "its carrots" but keeps being chased by the farmer that wants to "steal" its carrots. Help this delusional rabbit to escape from the clutches of the farmer and retreat to the safety of its hole.


## Features ✒️
* Player sprite (rabbit)
* Mob (farmer and puddles of water)
* Collectables (carrots and hearts)
* Lives counter


## Getting Started 📑
1. Install the files attached to the repository

2. Open the "Rabbit farmer" application file

3. A message will pop-up warning about the credibility of the file
   * Select Run file
   * Another message will pop up, click "Run anyway"


## Usage 📊

* Click on the "Start" button.
* To move the rabbit, use the WASD keys:
  * W (up)
  * A (left)
  * S (down)
  * D (right)
* Each time the rabbit collides with a farmer or enters a puddle, the rabbit looses a life (you have 3).
* Collect all the carrots for the rabbit hole to appear.
* Collecting the hearts will give the rabbit a shield allowing it to "attack" the farmers without loosing any lives.
* Entering the rabit hole will take you to the next level.
